01 — The Task

What is 2D Bin Packing?

You have a pallet of fixed size and a set of boxes with different dimensions. The goal: fit as many boxes as possible without overlaps, maximizing space utilization.

A classic optimization problem in logistics and manufacturing. The benchmark required building a complete desktop application — interactive GUI, solver algorithms, input validation, and system logging.

03 — The Challenge

Why is the GUI the hardest part?

GUI stands for Graphical User Interface — what users actually see and click. AI models trained on massive amounts of web code can produce beautiful websites easily. This project required PyQt5 — a Python library for building native desktop apps (programs installed and running on your computer, not in a browser) — with far less training data and no visual feedback loop.

✓ Web (HTML/CSS/JS)

Massive training data. AI produces polished, responsive UIs on the first try. Instant browser preview for feedback.

AI confidence — high
✗ Desktop (PyQt5)

Limited training data. Specialized widgets. The agent writes code but cannot see the rendered result — no automatic visual feedback.

AI confidence — needs guidance

Original plan: Use Figma → HTML → PyQt pipeline. Cursor supports Figma integration, but it requires Figma's paid plan. Adding another subscription wasn't worth it.

What happened: I let the AI agent handle design autonomously, using reference screenshots of award-winning interfaces. This saved hours of manual design work and produced better results than expected.

04 — The Workflow

Skills, Sub-agents & Rules

The biggest lesson: how you configure the AI agent matters more than which model you use. Cursor lets you define persistent instructions that guide the agent's behavior — similar to setting up a Claude Project with custom instructions, but for code development.

01 — RULES

Project Rules

Persistent instructions extracted from the specification. Instead of feeding the full PDF every prompt (wasting tokens), the agent summarized key requirements into compact rules — architecture, output format, validation.

≈ Claude Project instructions
02 — SKILLS

Specialized Knowledge

Knowledge files teaching the agent how to approach specific tasks. My "PyQt GUI Front-End Design" skill defined a complete design methodology — visual hierarchy, styling states, verification checklist.

≈ Claude Knowledge base
03 — SUB-AGENTS

Autonomous Reviewers

Agents called by the main agent when needed. My "senior-product-ui-critic" evaluates layout hierarchy, spacing, color, visual authority — UX expertise I couldn't articulate myself.

≈ Automated QA reviewer
⚠

Why this matters: After ~20 prompts, the agent forgets original architecture. It won't check the spec PDF even if the file is in the project. Rules and Skills act as persistent, compact memory — and save tokens by replacing bulky source documents.

07 — Takeaways

What I Learned

✓ WORKED WELL

Strengths

  • Skills + Sub-agents improved quality from the very first prompt
  • AI handled design decisions well when given proper reference material
  • Screenshot-based feedback loop was effective for desktop GUI
  • Restarting with better preparation after Composer 2 paid off significantly
✗ CHALLENGING

Pain Points

  • PyQt5 limited training data — more mistakes than with web tech
  • Agent loses project context after ~20 prompts without rules
  • No automatic visual feedback for desktop apps (yet)
  • Token management requires planning — first shot consumes the most
💡 TOKENS

Token Economy

  • Rules + Skills reduce waste with compact persistent context
  • Full spec PDF every prompt = token burn — extract key rules instead
  • Well-prepared first shot saves more than multiple correction rounds
→ RECOMMENDATION

For Teams

  • Configure Rules, Skills, Sub-agents before the first build
  • Use reference screenshots as design input — the agent understands visual language
  • Treat AI development as collaboration, not one-shot generation
  • Save a backup before every large agent task — if the result breaks things, you can restore in seconds instead of spending dozens of messages asking the agent to undo its own work
